## التعديلات
1. **الخطوط لا تعطّل الرسم:** تُحمَّل بـ `preload` + `onload` بدل `stylesheet` المعطِّل، مع بديل `<noscript>`.
2. **خط الرقعة مُقلَّص:** يُحمَّل بحروف «أبو أنس البكالي / حبة كاش وحبة بلاش» فقط (`&text=`) بدل الخط كاملًا.
3. **أوزان خطوط أقل:** IBM Plex من 4 أوزان إلى 2 (300، 500).
4. **صور الواجهة أخف:** جوال 101→58KB، ديسكتوب 197→114KB (1600px بدل 2000px).
5. **حركة البداية أسرع:** تأخير ظهور العنوان من 0.45ث إلى 0.1ث.
6. **`content-visibility:auto`** للأقسام البعيدة: المتصفح لا يرسمها إلا عند الاقتراب منها.
7. **`dns-prefetch`** لخرائط Google، والخريطة نفسها لا تُحمَّل إلا عند الاقتراب منها (موجود من قبل).

## ملاحظات صريحة
- **صورة الواجهة (LCP) تحسنت قليلًا فقط (~40ms)**: أغلب وقتها هو تأخير الشبكة نفسها. التحسن الأكبر سيأتي من الاستضافة على CDN (مثل GitHub Pages أو Cloudflare) بدل سيرفر المعاينة.
- عدد الطلبات زاد واحدًا لأن خط الرقعة صار ملفًا مستقلًا مُقلَّصًا — الحجم الكلي أقل.
- بعد التعديل: **0 أخطاء كونسول، 0 ملفات مفقودة، 0 تمرير أفقي**، والخطوط تظهر صحيحة (تم التحقق بلقطة شاشة).
